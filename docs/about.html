About the project

Esports365

A student-designed esports tracking experience inspired by the convenience of mainstream scores apps, built with HTML, CSS and JavaScript.

Problem

Esports fans follow multiple games and teams, but match schedules, scores and streaming information can be scattered across platforms. Finding one team’s upcoming events takes time.

Our solution

Esports365 provides a central website where visitors choose a favorite team, explore upcoming fixtures and review previous results in a clear dark-themed interface.

Features

  • Team selection based on game
  • Dashboard featuring chosen team and recent results
  • Matches page with filters and demo streaming platforms
  • Responsive layouts and accessible form fields
